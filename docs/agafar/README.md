# AGAFAR: исходники документов

Источник профиля: принятый commit `3574cc1` части T-20261112-093.
Документы: T-20261112-094; выпуск и публичная ссылка: T-20261112-095.

Стандарт: как у DREAMCOS/DONGDONGGURIMOO/FAU, две ссылки на отдельные PDF:
презентация компании с ассортиментом и документ «как работаем». Формат A4,
обложка с оригинальной фотографией, общий бренд Teranova и локализованный
контент профиля. Композиция следует спокойному клиническому оформлению AGAFAR:
тёмный синий текст, светлая бумага, фотографии без генерации и декоративных
эффектов. Презентация предназначена для чтения, а не выступления на экране.

Общий HTML-дек терял бы фотографии аппаратов, второй кадр Turn Up и описания
20 продуктов; `content.terms` здесь пуст. Поэтому AGAFAR использует отдельную
композицию в том же конвейере и наборе имён файлов. Документ «как работаем»
берёт только descriptor, CTA, terms_disc и exportNote профиля. Новых сроков,
обязательств и условий нет. Это PDF-презентация, отдельный PPTX не создаётся.

## Генерация и проверка

```sh
node scripts/gen-supplier-pdfs.mjs agafar
python3 scripts/check-agafar-pdfs.py --dist --report /tmp/agafar-checks.json
```

Нужны установленные PyMuPDF и Pillow; сеть и Chrome не используются.
`PDF_LANGS=ru,en` ограничивает диагностический прогон, `PDF_OUT` задаёт
временный каталог. Перед сдачей обязателен полный прогон без PDF_LANGS.
При ином Python его можно задать через PDF_PYTHON. Список языков берётся из
`src/i18n/locale-policy.mjs`; пропуск данных или изображения останавливает
сборку. Набор каждого PDF не уменьшается ради вмещения: переполнение вызывает
ошибку. Шрифты встроены; хинди использует PDF ActualText для правильного
копирования лигатур. Для иврита проверяются символы каждого блока: извлечение
смешанного RTL/LTR меняет порядок пунктуации; порядок слов проверяется глазами.
Проверка отдельно читает реальные glyph IDs. Для хинди используется Kohinoor, для японского и
иврита Arial Unicode (оба входят в macOS); на другой системе пути задаются
через AGAFAR_HINDI_FONT и AGAFAR_UNICODE_FONT. Шрифты не загружаются из сети.

`agafar-<presentation|terms>-<lang>.json` хранит все напечатанные строки,
их размеры и координаты, использованные фото и SHA-256 исходников.
`manifest.json` содержит хэши 26 PDF. Исходниками остаются эти JSON,
`scripts/gen-agafar-pdfs.py` и канонические JSON профиля/каталога.
Картинки внутри PDF уменьшены до разрешения чтения; исходные файлы не меняются.
Два кадра Turn Up используют принятые viewport093, без интерфейса телефона и
чёрных полей. Служебный consentNote и закрытые цены не печатаются.

## Что означает «на всех языках»

Тексты документа взяты из 13 локализованных профилей. Надписи на оригинальных
упаковках и рекламной графике остаются на языке производителя (EN/KO).
В частности, Point Plus и Turn Up содержат рекламные свойства и знаки,
которые не являются независимым подтверждением эффективности или регистрации.
PLAZION содержит Better Absorption / Deeper Penetration, без прежних
hair growth/Botox/inflammation. Цен внутри использованных изображений нет.
Видимые подписи и описания аппаратов переведены; полного перевода пикселей
оригинальных фотографий не заявляем.

Полный реестр требований и независимая редактура изображений передаются в
`AI_COORDINATION/Codex/evidence/T-20261112-094/` вместе с реестром093.
Browser QA ссылок и блока документов выполняется отдельно: наличие HTML href
и PDF не доказывает клик или отсутствие переполнения кнопок.
