## Как разбирались сырые файлы

53 файла в `raw-images/` — несортированный вывод `pdfimages` из Company
Introduction (EN) и леафлета (EN). Примерно половина — служебные/маскирующие
слои PDF (почти чёрный холст с едва заметным фрагментом: img-000-дубли,
img-005, img-007, img-009, img-013, img-016, img-017, img-021, img-022,
img-024–032, img-052, img-053) — визуально проверены, в профиль не идут.

Отдельно повезло: `img-041.jpg`…`img-051.jpg` (11 файлов подряд, все
768×576, без поворота) — это ровно 11 «hero-shot» с колл-аут линией на белом
фоне, по одному на каждый продукт, в том же порядке, что и слайды
презентации. Это и есть основной источник фото.

## Предложенные brandColors

```
{ deep: '#1A1A1A', sky: '#B9B2A6', accent: '#C9A876', bg: '#F7F4EF' }
```

Обоснование — по реальным паксшотам (не по памяти):
- **deep** `#1A1A1A` — собственный чёрный CETERA с упаковок (THETHERAPY,
  CEMEDIC GEL тёмные варианты, тюбик SOLARTONING на чёрном фоне в
  `img-014.jpg`) и логотипа.
- **sky** `#B9B2A6` — металлик крышки THETHERAPY/SOLARTONING (тёплый
  серебристо-бежевый, видно на `img-014.jpg`, `img-041.jpg`).
- **accent** `#C9A876` — тёплый кремовый/золотистый тон флаконов
  CEMEDIC GEL и MILKENCREME (`img-049.jpg`, `img-058.jpg`).
- **bg** `#F7F4EF` — светлый тёплый нейтральный фон карточки, стандартный
  паттерн для косметических профилей (ближе к белому, чем холодный серый).

Это предложение, не факт о бренде: компания не присылала фирменную
палитру (как и у ABELTY/DOOBOM — брендбука не было). Координатор может
скорректировать перед регистрацией в `suppliers.ts`.
