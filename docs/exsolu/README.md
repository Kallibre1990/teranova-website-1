- **Блоки страницы.** Общего блока, подтверждённого всеми тремя эталонами

  изобретать общий список секций сверх собственной структуры профиля.

  как нижний ориентир (не требование к сверх-числу); это ровно зона
  T-20261126-026.
- **Типы PDF на странице профиля.** Общий для всех трёх эталонов тип (после
  исключения запрещённого `price`) — `presentation` и `terms`.
  - `presentation` — закрывается тремя манифестными PDF из §2 (после
    перевода/вёрстки в T-20261126-025); самостоятельного решения не

  - `terms` — подтверждённый пробел: ни один из трёх манифестных файлов не
    является документом условий поставки/образцов. Отдельного PDF «terms»
    поставщик не присылал; создавать его из домыслов нельзя. Решение по
    этому пробелу — за T-20261126-025 (либо запросить у поставщика, либо
    закрыть вопросом Ирине/Антону, либо оставить блок без PDF).
- **Изображения.** Счётчик эталонов (58/46/74) — описательный факт, не

- **Прайс-лист как третий/четвёртый файл.** Не заводится ради количества —
