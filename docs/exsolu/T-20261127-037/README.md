## Незакрытые критерии

**Не готово к приёмке или выпуску.** Места без фото не выполняют требование
полноценной качественной витрины. В доступных официальных PDF нет пригодных
замен семи миниатюр; увеличение DPI не добавит детализации. Нужен пригодный
официальный материал через разрешённый внутренний контур, без самостоятельной
переписки worker-а. Требование не снято и не заменено заглушкой.

Нужно повторить browser QA на 320/390/600/680/860/940/1280, изучить скриншоты
и контраст/наезды/rendered pixels. Точки 600/680 и 860/940 окружают реальные
media 640/900. До/после выше — сравнение структуры, **не визуальная приёмка**.
Новые живые эталоны в этом проходе не открывались (внешний контур запрещён);
манифест 036 хранит сравнение трёх эталонов, но их browser QA также не завершён.
