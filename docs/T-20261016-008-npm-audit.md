# T-20261016-008 — npm audit, безопасное обновление

сайт собирается в статический HTML и обслуживается Cloudflare Pages. Ни один
из пакетов audit не попадает в состав того, что отдаётся браузеру: все 12 —
только инструменты сборки (Astro/Vite/esbuild/PostCSS и их цепочка), не
runtime-зависимости продакшена.

Примечание: на момент создания карточки (16.10) `npm audit` показывал 11
записей. На 03.11 — 12: новая уязвимость `astro` (incomplete fix for
CVE-2026-54298) опубликована после создания карточки. Число 2520 страниц в
карточке тоже устарело — сайт выросс с 16.10 (KOY territories и другие
правки); на main без каких-либо изменений сборка уже даёт 3408 страниц
(проверено отдельно на чистом main до применения этой правки).

Применено: `npm audit fix` (без `--force`) — изменил только `package-lock.json`
(46 пакетов пересчитаны на совместимые версии в допустимом диапазоне semver),
`package.json` не менялся, прямых зависимостей не трогал.

Проверки:
- `npm audit --json` после фикса: 3 оставшихся (astro, esbuild, sharp — все три
  требуют `--force`), список совпадает с п. 10–12.
- `npm run build`: 3408 страниц, без ошибок, `postbuild` (`verify-home-locale.mjs`)
  прошёл.
- `npm run test:i18n`: падает на `scripts/test-dist-verifier.mjs` (zh-локаль,
  `/zh/catalog/moz-science/`, `/zh/catalog/oavo/`, `/zh/catalog/toptrend/` —
  hreflang/canonical/og несоответствия). Проверено отдельно на чистом main
  (без этой правки) — тот же сбой воспроизводится без каких-либо изменений,
  значит это не регрессия от обновления пакетов, а предсуществующий дефект.
  Требует отдельной карточки (zh-локаль каталога), не входит в эту.
- История ветки: только один коммит с `npm audit fix` (без `--force`),
  изменён только `package-lock.json`.

Незакрытые уязвимости (astro/esbuild/sharp): причина — требуют `npm audit fix
--force` (мажорное обновление Astro 6→7), а условие карточки — обновления
только без `--force`. Все три пакета используются исключительно на этапе
`astro build` (генерация статики), не входят в runtime, отдаваемый
пользователю. Решение о мажорном обновлении Astro — отдельная задача с
собственной проверкой (breaking changes в API компонентов), не безопасное
патч-обновление.
